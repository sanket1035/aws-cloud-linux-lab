# AWS Cloud Deployment & Linux Server Lab

## Objective
Learn and document the deployment of a Linux web server
using AWS EC2 and Nginx.

## Architecture
User → Internet → AWS EC2 → Nginx → Static Website

## Technologies
- AWS EC2
- Linux
- Nginx
- SSH
- HTTP/HTTPS
- Git/GitHub

## What I learned
- EC2 instance basics
- Linux server administration
- SSH
- Security groups
- HTTP ports
- Nginx
- Basic troubleshooting
